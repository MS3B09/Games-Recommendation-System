# Game Discovery

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Approved: React/TypeScript/Vite, Tailwind CSS, modular Python/FastAPI, one PostgreSQL/pgvector database. Netlify frontend, FastAPI Cloud Hobby backend (owner-selected replacement for Render), Supabase Free database. No accounts.

## Users
Gamers looking for their next game; recruiters and clients assessing full-stack and AI/ML engineering.

## Product Purpose
Help players find games through favorite titles, natural-language taste and explicit constraints. Demonstrate measured, grounded recommendation engineering in an immediately accessible guest experience.

## Operating Context
Desktop and mobile browsers; free hosting can cold-start or pause. Developer collection/indexing/evaluation jobs run sequentially on an 8 GB CPU-only machine.

## Capabilities and Constraints
AGENTS.md governs product scope; IMPLEMENTATION_PLAN.md governs milestones. M1 is a health-connected walking skeleton only. Catalog import, search and recommendations begin in M2; browser persistence/feedback in M3; conversational discovery in M4. US store region/USD, recorded freshness, no promised live prices. Scrapling is the sole scraping framework. No next milestone without explicit owner permission.

## Brand Commitments
User-approved dark, refined presentation with restrained accents. Image-rich game presentation belongs to later discovery surfaces. “Game Discovery” is an approved temporary M1 title, not a final brand decision. User confirmed a minimal foundation page with real connection state, manual retry and API documentation links.

## Evidence on Hand
docs/progress.md and docs/reports/feasibility.md record measured resource results. The metadata schema is initialized but no catalog is active. No live recommendation demo or evaluated relevance improvement exists yet.

## Product Principles
- Ground claims in source evidence.
- Show empty, unavailable and loading states distinctly.
- Keep the core useful without hosted language-model inference.
- Preserve the free-only, lean architecture.

## Accessibility & Inclusion
Responsive layouts, semantic controls, keyboard navigation, visible focus, readable contrast and reduced-motion support.
