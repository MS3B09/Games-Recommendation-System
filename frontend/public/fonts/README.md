# Current typography

Anton Regular is self-hosted, unmodified, from
https://github.com/google/fonts/tree/main/ofl/anton . Its original SIL Open Font
License is retained in `Anton-OFL.txt`. It supplies Current's display headings.
Body and controls use the existing self-hosted `@fontsource-variable/manrope`
package. The former study-only faces and Fantasy faces are no longer used.
