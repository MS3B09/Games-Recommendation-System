Owner approved this revision after the October 28 classifier-led follow-up failures. This supersedes the earlier no-server-memory restriction for the assistant only. Existing frozen R4 artifacts remain historical and must not be resumed against new source.

- A new `/api/v2/assistant` surface uses a normal model conversation and bounded catalog/history tools. The old v1 endpoint remains compatible for old tabs and experiments.
- Maximum three model calls per turn: up to two rounds of read-only tools (four per round/six total), followed by a final answer with tools disabled. Ordinary conversation uses one call; a simple lookup normally uses two. Two dependent rounds allow history retrieval followed by catalog lookup. Tool-validation feedback uses this same fixed budget; there are no automatic HTTP/provider retries, classifier, game-specific branch or unbounded loop.
- Catalog tools expose paginated search with exact scope/count/completeness, arbitrary game details and field pagination, and existing hybrid recommendations with explicit hard filters. Missing information is distinct from negative evidence. UI cards are canonical; suppressing unrequested technical IDs in free-form prose is still a measured quality issue, not a guaranteed property.
- PostgreSQL stores the complete accepted conversation and attempt history, full displayed card identities/evidence, user preference/correction working memory and archived tool results. A random per-chat capability is hashed at rest; no accounts or client database access. Execute-only runtime functions and RLS protect storage. Independent New chat starts empty.
- The model sees recent chronological exchanges, sourced working memory and an entity index. Older original events remain available through paginated/searchable history tools; context omissions are explicitly marked. No transcript deletion during compaction. Storage exhaustion is explicit; it never silently drops old records.
- Guest storage is finite: explicit per-conversation and shared archive ceilings, no paid service or background summarizer. New chat/clear offer actual server erasure and preserve current browser focus/card/save behavior.
- Factual answer sections reference supplied catalog evidence, validated against the source set; free-form paraphrase entailment still needs evaluation. Test scope includes diverse unseen multi-turn sessions, long archive retrieval, isolation, corrections, paging, failures, idempotency and natural repair. Live checks are separate from scripted mechanics and historical R4 acceptance.
