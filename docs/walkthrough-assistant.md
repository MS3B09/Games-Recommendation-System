## 1. Main discovery, useful without AI

1. Start/restart the API and preview as described in [assistant operations](operations-assistant.md); final preview targets API:8001.
2. Choose favorite artwork in **Your taste**. Adjust **My limits** and submit **Find my next game**.
3. Inspect canonical game details, recorded US/USD date/price and platform facts. Recorded prices are not today's Steam quotes.
4. Save a game, open `/saved`, then reload. Bookmarks/preferences are **Saved on this device**, not an account or cross-device sync.
5. **Already Played** or **Not For Me** hides that title without automatically replacing the other rows. The next explicit search uses device feedback.
