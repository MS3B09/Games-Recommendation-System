## Interaction contracts

- Main discovery: favorites + My limits + stored feedback. No text, conversation or saved list is sent. Up to ten results, exact-title feedback dismissal preserves other rows/order without auto-replacement. Next explicit discovery applies affinities. Save has no ranking effect.
- `POST /api/v1/chat`: only `message`, bounded `messages` and chat-local `state`. Unversioned state uses the legacy adapter; explicit `version:2` accepts/returns full v2 state. Unknown versions are rejected; omitted state keeps the old default. Main `favorite_ids`, `preferences` and `feedback` are invalid. Six finite stages validate interpretation, retrieve canonical evidence and check output through the metered provider. Neutral defaults have no budget/platform/mode/genre requirements. Facts bypass recommendation conditions/exclusions and explain mismatches; catalog text is untrusted data.
- Browser key `game-discovery:assistant` now uses envelope version2:20messages /2,000chars each /12,000total,12cached cards,2,000char draft, bounded v2 memory and optional exact pending request, within500,000characters. Fully validated v1 migration retains transcript/cards/draft and quarantines old requirements/exclusions, without inventing provenance or using main zero-minimum/default controls. Active origins survive trimming/reload. Provider projection stays within last-eight/700chars and12,000UTF-8 JSON bytes, omitting full provenance/state.
- Chat cards retain image/title/dated price, essential in-panel facts and Save/Steam. No chat feedback buttons. Played/dislike/exclusion undo resolves canonical title/alias or recent position; ambiguity clarifies, facts remain inspectable. Shared Save sends no saved list to AI. V2 memory round-trips through browser/API.
- Close/reopen/reload retain chat. Unfinished saved user turns expose retry; exact pending snapshots preserve pre-turn state/context and do not duplicate the visible user message, including after trimming/reload. Retried inference still follows normal quota accounting; the API has no persistent deduplication. New chat clears only chat and aborts pending work. Clear my saved data invalidates work across tabs. Corrupt/future/oversized storage is protected until explicit New chat; blocked storage is memory-only with guidance. Old/incompatible API responses preserve v2 storage/pending and explain retry/reset rather than downgrading. The legacy main-form session key is never imported.
- Desktop panel is nonmodal. At <=640px it is modal: background inert, forward/reverse focus containment and Escape/Close restoring launcher focus. Background inertness is removed on close, resize or unmount.
- AI may answer or clarify without cards. Catalog recommendations/cards are verified, not invented; card facts/links/prices are database-rendered, optional fact claims require exact evidence. Natural prose is plain text, instructed to use supplied facts and disclose subjective uncertainty; its overall factual quality has **not** been evaluated with a live model. Unsupported selections/claims, invalid ranges, transport failures or unavailable quota produce an explicit retryable error. No-match results retain chat requirements.
