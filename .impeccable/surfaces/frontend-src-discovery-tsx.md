# M2 discovery surface

Mode: Operate. User confirmed installed frontend skills and the task-first layout in this session. Scope: favorites, explicit filters, real catalog cards, details and evidence; M3 persistence and M4 language discovery remain future milestones.

## Direction contract

THESIS: Make favorite-to-shortlist discovery directly usable, with source facts beside the games rather than an opaque match percentage.

OWN-WORLD: Extend the confirmed blue-dark Manrope/parchment foundation. Open work areas, hairlines, native controls, quiet selection treatment; Steam header art supplies color and atmosphere.

STORY: Select favorite games, set required constraints, discover a shortlist, inspect a source-backed reason and recorded-price date, then adjust criteria.

FIRST VIEWPORT: Compact introduction and US/USD freshness above a two-column workspace. A bounded criteria rail holds search, selected favorites, budget and expandable controls; the larger result area holds real-game artwork, titles and reasons. Mobile stacks controls before results.

FORM: User-pinned precise layout, confirmed via structured question; no concept seed is required for this narrow milestone. Signature interaction: a card's “Why this game?” disclosure reveals reasons and their actual evidence sources inline.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Artwork is remote source-provided Steam header imagery, retained with source URL and collection timestamp in each catalog game; no generated or shipping local raster assets.
